# 🌦️ WeatherGPT

WeatherGPT is an AI-powered weather assistant designed to provide real-time weather information and intelligent weather insights through a simple and user-friendly web interface.

## ✨ Features

- 🌤️ Real-time weather information
- 📍 Location-based weather updates
- 🌡️ Temperature and weather conditions
- 💧 Humidity information
- 💨 Wind speed and direction
- 🤖 AI-powered weather analysis
- 🔥 Firebase integration
- 💻 User-friendly web interface
- 📱 Responsive design
