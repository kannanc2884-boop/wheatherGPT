# WeatherGPT Frontend Redesign

This version is a structural redesign, not a color patch. It borrows high-level interaction ideas from modern tech-festival websites such as graVITas: oversized display typography, kinetic marquees, rotating orbital graphics, playful bright color blocks, bold editorial section transitions, event-at-a-glance bento modules, and motion-led hierarchy. WeatherGPT branding, layouts, wording, assets, and code remain original.

## Palette
- Paper / cream: #F3EDE1 / #FFFAF0
- Electric blue: #3F45FF
- Acid lime: #C9F447
- Coral: #FF684D
- Festival yellow: #FFD84D
- Sky: #83E5FF
- Pink: #FF8DCC
- Ink: #18181B

## Motion
- Intro splash
- Rotating weather orbits
- Floating data tickets
- Continuous technology marquee
- IntersectionObserver scroll reveals
- Hover lift / hard-shadow cards
- Animated ambient gradients

No VIT/graVITas logos, text assets, imagery, or proprietary visual assets are copied.
