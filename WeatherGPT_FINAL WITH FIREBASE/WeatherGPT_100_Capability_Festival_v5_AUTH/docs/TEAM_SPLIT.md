# Six-person prototype split

1. **Frontend / UX:** command center, responsiveness, motion, accessibility.
2. **Weather data:** Open-Meteo variables, geocoding, AQI, data validation.
3. **n8n:** workflows, webhooks, environment variables, error handling.
4. **AI:** Gemini prompt, multilingual output, mode testing, hallucination tests.
5. **Risk + alerts:** scoring rules, official SACHET verification, source integrity.
6. **Integration + QA:** maps, charts, PWA, cross-browser testing, demo script.
